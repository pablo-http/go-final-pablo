# Планировщик задач

Это веб-сервер на Go — простой TODO-лист с REST API. Можно добавлять задачи, редактировать их, удалять и отмечать выполненными. Задачи могут повторяться по заданному правилу — например, каждый день или раз в неделю.

Фронт был готов заранее в папке `web/`. То бишь достаточно запустить приложение и открыть по урлу

## Как запустить

Установка зависимостей:

```bash
go mod tidy
```

Запуск сервера:

```bash
go run .
```

Открой в браузере `http://localhost:7540/` 

## Переменные окружения

Можно настроить след вещи через переменные окружения:

- `TODO_PORT` — порт сервера, по умолчанию `7540`
- `TODO_DBFILE` — путь к файлу базы данных, по умолчанию `scheduler.db`
- `TODO_PASSWORD` — пароль для входа. Если не задан, аутентификация отключена

Пример:

```bash
TODO_PORT=8080 TODO_PASSWORD=12345 go run .
```

Если задан пароль, при открытии сайта появится страница входа

## Как запустить тесты

Сначала запусти сервер в одном терминале, потом в другом сами тесты:

```bash
go test ./tests
```

Если надо проверить правила повторения `w` и `m` — поставь `FullNextDate = true` в файле `tests/settings.go`.

Если надо проверить поиск задач -  поставь `Search = true` там же

Если сервер запущен с паролем — надо зайти через браузер, копирнуть значение куки `token` и вставить его в `Token` в `tests/settings.go`.

## Что сделано дополнительно (задания со звёздочкой)

- Порт и путь к БД настраиваются через переменные окружения
- Полная поддержка правил повторения: по дням, по годам, по дням недели, по дням месяца
- Поиск задач по названию, комментарию и дате
- авторизация через жвт


## Docker как последнее задание

Собрать образ:

\```bash
docker build -t go-final-pablo .
\```

Запустить контейнер:

\```bash
mkdir -p ~/scheduler-data
docker run -p 7540:7540 \
  -v ~/scheduler-data:/app/data \
  -e TODO_PASSWORD=12345 \
  go-final-pablo
\```

Открыть в браузере `http://localhost:7540/`.

База данных хранится в папке `~/scheduler-data` на хосте.
